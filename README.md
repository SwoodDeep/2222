# CodeBrain

**CodeBrain** — локальное приложение для глубокого статического анализа исходного кода и интерактивной 3D-визуализации архитектуры программных проектов в виде «цифрового мозга».

Весь анализ выполняется **локально** на вашей машине. Анализируемый код никогда не запускается, не изменяется и не отправляется на внешние серверы. AI-модуль (опциональный) отправляет только тщательно отобранный контекст на указанный вами endpoint, при этом секреты и `.env` автоматически исключаются и редактируются.

## Запуск

```bash
cd codebrain
npm install        # один раз
npm start          # или: node server/index.js
# откройте http://127.0.0.1:4173
```

Требуется Node.js ≥ 20. Порт можно задать переменной окружения: `PORT=8080 npm start`.
Каталог данных (кэш, проекты, история, настройки AI) — `~/.codebrain` (переопределяется `CODEBRAIN_DATA_DIR`).

В браузере: нажмите **«+ Проект»**, укажите путь к папке проекта — сканирование начнётся автоматически. Прогресс идёт в реальном времени (SSE); повторный запуск использует инкрементальный кэш, изменения файлов отслеживаются автоматически (watch-режим).

## Возможности

### Анализ (бэкенд, `server/`)
- **File Scanner** — рекурсивный обход, игнорирование `node_modules`, `.git`, venv, dist/build, бинарных файлов, больших файлов; учитывается `.gitignore` и `.git/info/exclude`; симлинки не отслеживаются; защита от path traversal на уровне API.
- **Code Parsers** — расширяемый реестр (`server/parsers/`). JavaScript/TypeScript/JSX/TSX парсятся настоящим AST (TypeScript compiler API, cyclomatic complexity считается по AST). Python, Java/Kotlin, C#, Go, Rust, PHP, C/C++, HTML, CSS, Vue, Svelte, JSON, YAML, TOML/INI/.env, SQL, Markdown, shell, Dockerfile — структурные парсеры. Новый язык = один файл + `registerParser()`.
- Извлекаются: импорты/экспорты, функции/классы/методы/наследование, компоненты (React/Vue/Svelte), API-роуты (Express, Flask, FastAPI, Spring, ASP.NET, Go mux, Actix/Rocket, Laravel/Slim), HTTP-вызовы (fetch/axios/XHR/requests/reqwest/HttpClient…), WebSocket, обращения к БД (SQL/ORM), обработчики событий, точки входа (package.json scripts/main/bin, Dockerfile, workflows).
- **Graph Engine** — граф реальных зависимостей. Рёбра имеют уверенность: `certain` (разрешённый импорт, наследование, роут→обработчик, фактический HTTP/WS/DB-вызов) и `inferred` (совпадение имён вызовов, сопоставление URL роутам). Ничего не выдумывается: неразрешённые импорты считаются отдельно (`unresolvedImports`).
- **Analysis Engine** — Tarjan SCC (циклические зависимости), неиспользуемые экспорты, цикломатическая сложность и «god-компоненты», дублирование (шинглы 6 строк),潜在ные секреты (имена файлов + паттерны строк; значения не сохраняются), orphan-файлы.
- **Impact analysis** — обратное замыкание зависимостей от выбранного файла: кто будет затронут изменением.
- **Производительность** — worker threads (пул = CPU-1), инкрементальный кэш по `mtime+size` в `~/.codebrain/cache`, watch-режим с инкрементальным пересканом, отменa сканирования, потоковый прогресс (SSE), пространственная кластеризация и LOD на визуализации, сидированный force-directed layout на сервере.
- **Хранение** — реестр проектов, история снимков анализа (сравнение «до/после»), Git-интеграция (ветка, коммиты, dirty-файлы), экспорт графа в JSON/SVG, архитектурный отчёт в Markdown.
- **AI Integration** — OpenAI-compatible / Ollama / custom endpoint (SSE-стриминг ответов). Интеллектуальный отбор контекста ( скоринг по токенам вопроса против путей/символов/роутов), урезка сниппетов, редактирование секретов, исключение `.env`, system-prompt с защитой от prompt injection (код = данные). Вопросы типа «как работает авторизация?» — ответы со ссылками `path:line`.

### Визуализация и UI (фронтенд, `public/`)
- **Brain 3D** (Three.js, шейдеры на GPU): узлы-компоненты с размером по архитектурной значимости, светящиеся рёбра, анимированные импульсы вдоль связей (в шейдере), авто-вращение, OrbitControls (вращение/зум/панорама), raycast-выбор, подсветка цепочки зависимостей от выбранного узла, агрегация в кластеры при >2200 узлах (кнопка «Кластеры»), переключение **2D/3D**, кнопка «⤢» (вписать в экран).
- Режимы на одной модели данных (синхронизированы выбором): **Brain 3D, Архитектура (слои), Зависимости, Data Flow, API Map (клиент↔сервер), Risk Map, Файлы, Impact**.
- Цвета категорий: frontend, backend, API, БД, сервисы, конфиги, тесты, docs, внешние пакеты, проблемные (секреты/циклы — красные).
- Левая панель: дерево проекта (ленивое раскрытие), поиск по файлам/символам/роутам, фильтры категорий (скрытие групп). Правая панель: карточка компонента (путь, назначение, LOC, метрики, входящие/исходящие зависимости с уверенностью, риски, ссылки на код). Нижняя панель: логи, просмотрщик кода с подсветкой (highlight.js), диагностика (статистика, риски, история, Git, экспорт), AI-чат.
- Изменяемые панели, полноэкранный режим, горячие клавиши (`1–8` режимы, `F` поиск, `R` скан, `B` нижняя панель, `G` 2D/3D, `Esc`), настройки хранятся в localStorage.

## Тесты

```bash
npm test          # 38 юнит-тестов на фикстуре с известными зависимостями
node tests/e2e-api.js   # 32 E2E-проверки HTTP API (нужен запущенный сервер)
npm run loadtest  # нагрузочный тест: 3000 файлов / ~159k строк
```

### Результаты (Node 22, 5 CPU, 6GB RAM)
- Фикстура `tests/fixtures/sample-app`: **38/38** — импорты, цикл `cycleA↔cycleB`, роуты Express/Flask, сопоставление `fetch('/api/users')` → `server/index.js`, WebSocket-узел, БД-рёбра, `.env` как секрет, неиспользуемый экспорт, impact `db.js → {index.js, auth.js}`.
- E2E API: **32/32** (включая блокировку path traversal `../../etc/passwd`).
- Нагрузочный тест: 3000 файлов / 158 993 строк — полный скан **~6.5 с**, heap **~70 MB**, граф 3004 узла / 5952 рёбер (JSON 2.2 MB); повторный скан из кэша **~1.6 с**; инкрементальный после изменения 50 файлов **~1.8 с**.
- Реальные проекты: сам CodeBrain (56 файлов, 830 мс, найден реальный цикл в парсерах), репозиторий **express** (177 файлов / 27k строк, ~1 с, 767 рёбер, 308 роутов, корректное ребро `lib/express.js → lib/application.js`).

## Известные ограничения
- JS/TS — настоящий AST; остальные языки — структурные эвристики (без полного AST), поэтому связи по вызовам для них помечаются `inferred`.
- Сопоставление клиентских URL с роутами — эвристика нормализации (`:id`, `{id}`, `<id>` → `{}`); при неоднозначности ребро получает `inferred`.
- Анализ данных (data flow) — на уровне «кто кого вызывает/дергает по HTTP/БД», а не полноценный taint-tracking переменных.
- Большие проекты (>~2.2k файлов) в Brain 3D автоматически/вручную агрегируются в кластеры; разворачивание кластера — по клику (агрегатные узлы), а не покомпонентно.
- Прогресс парсинга гранулярный по пачкам файлов; точность процента приблизительная.
- Браузерная часть проверена статически (синтаксис модулей, все ассеты отдаются 200); интерактивный прогон в браузере — на вашей стороне.

## Структура

```
server/
  index.js            HTTP API + SSE + статика
  config.js           пути, лимиты, игноры, паттерны секретов
  scanner/            обход ФС, .gitignore
  parsers/            реестр + парсеры языков (JS/TS — AST)
  workers/            worker-пул параллельного парсинга
  analysis/           symbol index, резолвер зависимостей, граф, анализ, impact
  storage/            кэш, проекты, история, watcher
  ai/                 AI-клиент (OpenAI/Ollama/custom), отбор контекста, редактирование
  git/                git-интеграция
public/               фронтенд (Three.js brain, canvas-виды, панели)
tests/                фикстура, юнит-тесты, E2E, нагрузочный тест
```
